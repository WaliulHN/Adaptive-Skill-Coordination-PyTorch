# Adaptive-Skill-Coordination-PyTorch

# Adaptive Skill Coordination (ASC) for Robotic Mobile Manipulation

This repository contains a PyTorch implementation of the neural network architectures described in the paper:
**"Adaptive Skill Coordination for Robotic Mobile Manipulation"** (Yokoyama et al.).

## Architecture Included
- Visual Encoders (CNN)
- Visuomotor Policies (MLP + GRU)
- Adaptive Skill Coordination (MoE Gating Network & Corrective Policy)

*Note: This code provides the neural network architecture and a dummy forward-pass test. Full training requires integration with the Habitat-Sim simulator.*
